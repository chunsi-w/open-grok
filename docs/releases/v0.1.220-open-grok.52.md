# Open Grok v0.1.220-open-grok.52

This release ports upstream Grok Build **0.2.118** (`780d1388`) and **0.2.119**
(`e5478eff`) into Open Grok after the previous sync through **0.2.117**.

## Auth and reliability

- **Expired external auth** — credentials that need interactive sign-in enter
  the login flow instead of looping on silent 401s.
- **External-binary auth** — provider-command sign-in is treated as a fresh
  login, not a headless refresh.
- **Single external refresh attempt** — one short headless refresh window
  before escalating to interactive auth.
- **MCP vendor kill-switch** — reported-on vendor-compat MCP kill switches are
  actually enforced on mid-session server updates.

## Tools and permissions

- **Always-allow pattern editor** — free-form bash glob patterns in addition
  to word-prefix scopes.
- **Read-only git auto-approve** — more common read-only git queries pass
  auto mode; write floors still defer to the classifier.
- **Path rules use request cwd** — permission globs for Read/Edit/Grep
  lexical-normalize and anchor to the requesting session’s cwd.
- **Truncated tool output** — short tool results that are only part of a
  larger log report the real full size.
- **Task completion framing** — huge background-task logs no longer grow
  completion notifications without bound.

## Sessions and interface

- **Optimistic pre-session model pick** — model selection before the session
  binds updates the UI immediately and applies when creation finishes.
- **Project directory picker removed** — recent-directory helpers remain for
  other surfaces.
- **Response top jump** — long answers show a clickable control that jumps to
  the start of the response.
- **Question cards** — Tab walks answers without losing focus to scrollback.
- **Resume picker** — Enter no longer tries to load a session from pasted
  garbage.
- **Plan preview** — Mermaid affordances and a more reliable plan-viewer
  scrollbar.
- **Background task races** — completion-before-backgrounded no longer
  resurrects finished tasks as Running.
- **Duplicate auto-recap suppression** — a live auto recap is dropped when
  scrollback already shows one since the last user prompt.

## Watching and telemetry

- **Nested checkouts skipped** in file watching so in-repo worktrees cannot
  stall startup.
- **Git head changed** notifications fire on same-branch commits.
- **Skill telemetry** — model-side skill reads count toward skill activation;
  skill dispatch carries a trigger (`slash_command` / `skill_md_read` /
  `skill_tool`).
- **OTLP gRPC TLS** — external collectors over `https://` work with optional
  customer CA bundles; settings gate self-opens after a bounded wait.

## Platform

- **Rust toolchain** bumped to **1.93.0**.
