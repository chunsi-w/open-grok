# Open Grok v0.1.220-open-grok.55

This release adds first-class Meta API support with Muse Spark models and
native hosted web search.

## Meta API

- **Muse Spark models** — adds `muse-spark-1.2`, `muse-spark-1.1`, and
  `muse-spark-1.2-contributor` to the model catalog.
- **Reasoning controls** — supports `low`, `medium`, `high`, and `xhigh`
  reasoning effort.
- **Hosted web search** — routes web searches through Meta's native cloud tool
  instead of the client-side search fallback.
- **Dynamic catalog** — refreshes the curated Muse Spark catalog from Meta's
  `/models` endpoint while preserving local capability metadata.

## Compatibility and Isolation

- Handles integral JSON timestamps encoded as floating-point values by the
  Meta Responses API.
- Keeps Meta API credentials host-scoped and isolated from xAI, Codex, and
  other provider credentials.
- Treats Meta as an API-key provider during startup, avoiding unrelated xAI
  login and subscription gates.
