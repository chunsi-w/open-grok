# Open Grok v0.1.220-open-grok.57

This release fixes Meta API (and Wafer AI) models not appearing after login
even when a valid API key was saved.

## Credential Trust Gate

- **Meta API** — stored `meta::api_key` credentials now resolve on the trusted
  `https://api.meta.ai` host, so Muse Spark models become selectable in
  `/model` after `/login meta` or Settings save.
- **Wafer AI** — the same host-scoped trust path now accepts stored
  `wafer::api_key` credentials for `https://pass.wafer.ai`.
- Custom / proxy endpoints remain fail-closed: stored provider keys are not
  sent outside each provider's trusted host.

## Install

irm https://github.com/mweinbach/open-grok/releases/latest/download/install.ps1 | iex
