# Open Grok v0.1.220-open-grok.56

This follow-up release completes the Meta API user interface and live
credential workflow introduced in `.55`.

## Meta Login and Settings

- **Login picker** — adds Meta API to the `/login` provider picker with live
  saved, missing, or environment-override credential status.
- **Direct command** — `/login meta` opens the secure Meta API-key editor from
  both active sessions and the agent dashboard.
- **Settings** — adds a masked `Meta API key` row with save, clear, reset, and
  environment-override behavior matching the other API-key providers.

## Live Runtime Updates

- Stores Meta credentials in the isolated `meta::api_key` auth scope and
  refreshes the Muse Spark catalog immediately.
- Rebinds loaded Meta sessions to the new credential without changing the
  selected model or reasoning effort.
- Pauses queued Meta prompts while credentials or samplers are changing and
  resumes them only after the new runtime is confirmed.
- Cancels Meta subagents before a credential change so stale credentials
  cannot remain active in child runtimes.
