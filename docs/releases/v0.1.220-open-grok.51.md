# Open Grok v0.1.220-open-grok.51

This release ports upstream Grok Build **0.2.117** (`a4221165`) into Open Grok
after the previous sync through **0.2.116**.

## Auth and reliability

- **401 retry budget** — `SentCredential` provenance on auth errors plus a
  per-turn retry schedule paced by a suspend-aware DualClock, so sleep and
  fail-closed missing-credential sends do not burn the authenticated budget.
- **Login failure classification** — interactive login errors are typed through
  OS/network classification for clearer telemetry.
- **Stop cancels compaction** — an in-flight `/compact` or auto-compact is
  aborted when the user stops the turn.

## Tools and permissions

- **Task wait ceiling** — blocking `get_task_output` / wait calls clamp to
  `OPENGROK_MAX_WAIT_BLOCK_MS` (default 10 minutes) and advertise the cap in
  tool descriptions.
- **Config edit protection** — permission and sandbox config under `.opengrok`
  and `$OPENGROK_HOME` cannot be silently rewritten by agent edits.

## Sessions and interface

- **Welcome workspace mode** — Sandbox | Local picker under `--chat` (Local
  remains behind the off-by-default `local-workspace` feature).
- **Faster resize** — terminal resize bursts coalesce on long fullscreen
  conversations.
- **Dashboard** — row delete arming and roster activity states.
- **Enterprise usage** — `/usage` and billing UI stay hidden for enterprise /
  external auth setups.
- **Session registry** — per-session resources consolidate with one-drop
  release; hub transport hardens writer close and liveness rearm.
