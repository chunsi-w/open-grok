# Open Grok v0.1.220-open-grok.54

This release adds team-scoped mailboxes for subagents and makes swarm
follow-up work safer and more predictable.

## Agent Collaboration

- **List agents** — inspect the active agents in the current team scope.
- **Send messages** — deliver bounded messages directly to another active
  agent without exposing them outside the team.
- **Follow up** — assign additional work to an idle root agent while preserving
  the existing agent conversation.
- **Wait for agents** — wait on specific teammates without polling their task
  output manually.

Mailbox messages are persisted in the root session for auditability, surfaced
as clearly marked untrusted input, and bounded to prevent runaway queues or
oversized payloads.

## Swarm Reliability

- Follow-up prompts no longer cancel live swarm members while orchestration is
  waiting for the cohort.
- `task`, `agent_swarm`, and `workflow` remain distinct tool surfaces with
  regression coverage guarding their contracts.
- Collaboration tools are exposed only when subagents are enabled.
