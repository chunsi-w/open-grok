# Open Grok v0.1.220-open-grok.58

This release hardens multi-provider reasoning and fast-routing behavior.

## Provider Reliability

- **Meta Muse Spark** — stateless Responses requests no longer replay expired
  opaque reasoning references after tool calls, while supported reasoning
  effort remains enabled.
- **Fireworks AI** — curated reasoning models expose low, medium, and high
  effort controls; Chat Completions forwards priority fast routing; concurrent
  requests are paced to reduce rate-limit bursts.
- **Wafer AI and OpenCode Go** — unsupported stale reasoning and service-tier
  fields are removed, and OpenCode catalog output limits no longer become
  oversized default request limits.
- **Subagents and model switching** — reasoning effort is preserved only when
  the effective refreshed model supports it.
- **Diagnostics** — inference retry and failure logs include sanitized provider,
  model, backend, effort, service-tier, status, and attempt information.

## Install

```sh
curl -fsSL https://github.com/mweinbach/open-grok/releases/latest/download/install.sh | bash
open-grok --version
```
