# Open Grok v0.1.220-open-grok.53

This release makes remaining opt-in / Advanced feature flags available in
Settings, with clearer descriptions that show when you select (click /
keyboard-focus) a flag.

## Settings → Advanced

New toggles for features that were previously config.toml / env-only:

- **Product telemetry** — anonymous product-analytics master switch
- **Remember-mode shortcut** — `#` on an empty prompt enters remember mode
- **Web fetch allow localhost** — loopback-only companion to Web fetch
- **Crash handler** — richer panic/crash reports
- **Mouse reporting toggle** — Ctrl+R / `/toggle-mouse-reporting`
- **Shell command suggestions** — history/path completions
- **AI shell suggestions** — model-backed shell completions
- **Sandbox auto-allow bash** — skip bash prompts when sandboxed
- **Respect .gitignore in tools** — search/file tools skip ignored paths

Existing Advanced flags (memory, LSP tools, web fetch, two-pass compaction,
non-Git warning, doom-loop recovery, subagent worktree snapshots) keep their
toggles and get fuller descriptions.

## Discoverability

- Advanced local feature-flag rows **auto-show their description when selected**
  (click or keyboard focus), so you get context without pressing Right /
  clicking `▸`. Hover alone does not expand.
- Other settings stay expand-on-demand.

## Fixes

- **Doom-loop recovery** Settings default now matches the runtime default
  (**on**), so resetting the row no longer silently disables recovery.
- **Remember-mode** gating reads through the shared local-feature-flag loader
  (effective config) instead of a raw user-config peek.
